# iOS · v3 Modern Ember — simulator evidence (2026-11-07)

iPhone 17 simulator (`1BD4732B-EC1A-4074-8C70-6AC369607185`), iOS 27.0, Debug build of
`design/modern-ember-ios`, driven through T3's device tools. Screens were reached with the
app's DEBUG fixtures (`-FlintUIPreview`, `-FlintUIPreviewSession harder`,
`-FlintUIPreviewHistory sample|complete`, `-FlintUIPreviewAuthorizationScenario transient`
for onboarding). The simulator has no Screen Time authority, so status pills, the Rules
"unavailable" notice and the You diagnostics show the honest degraded state; populated
rule/limit cards, Apple's app picker (05), the system shield (07) and break wait (09)
need a Screen Time–authorized device and are not shown here.

Reference boards: `design/modern-ember/M01…M16`.
